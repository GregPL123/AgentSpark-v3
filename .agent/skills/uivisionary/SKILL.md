# UIVisionary Skill

**Cel**  
Jestem odpowiedzialny za to, żeby aplikacja wyglądała i czuła się dokładnie tak samo (a nawet lepiej) jak oryginalny index.html.

**Kiedy mnie używać**  
- Wszystkie komponenty UI (Sheet, TopicCard, AgentCard, Chat, Modal itp.)
- globals.css + wszystkie animacje (shimmer, spring, msgIn, typing)
- mobile-first + safe-area + iOS bottom bar + swipe-to-dismiss
- ThemeProvider + long-press reset

**Jak pracować**  
- Zachowuję 1:1 wygląd i animacje z oryginału
- Używam framer-motion do wszystkich transition
- Piszę komponenty z pełną dostępnością (aria-*, roles)
- Testuję na mobile (100svh → 100dvh)
